1. キャンバス作成
X と Y はどちらも 1 始まりです。キャンバス再作成で現在の内容は消えます。
2. 色番号
例: 1=#040F / 2:#FF0000 / 3 -> #00CCFF / 4 #112233
現在色: なし
3. 命令入力
書き方の揺れはある程度吸収します。全角数字・全角記号もだいたい対応します。消す命令やクリア命令も使えます。反転は選択範囲にだけかかります。
例: 1 = #040F 2 -> #FF0000 X=2, Y=5〜3 を #040F で塗る x=4-6 y=2 2 X=2, Y=3-5 を消す erase x=7-9 y=1 copy x=2-4 y=3-6 paste x=8 y=3 左右反転 上下反転 選択解除 clear
4. 保存とメモ
PNG は透過で保存します。PSD は 1 レイヤー相当のフラット書き出しです。
「PNG+PSDまとめて保存」は、対応端末では 2 つのファイルを同じ名前でまとめて共有できます。
対応端末では保存先選択を試し、非対応環境では共有シートまたは通常ダウンロードに切り替えます。
下のキャンバスは 2 本指のピンチイン / ピンチアウト、または倍率ボタンで拡大縮小できます。
選択範囲は矢印で1マスずつ微調整できます。貼り付け位置を選ぶ中は、紫の枠を矢印で動かせます。
